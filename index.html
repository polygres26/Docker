Polygres

PolyAdvisor & PolyWire

Two tools for moving off Oracle/MySQL/MariaDB/SQL Server onto Postgres: assess how hard the migration is, then bridge your existing application to Postgres while you do it.

ghcr.io/polygres26/polyadvisor

PolyAdvisor

Connects to a source database (or takes an uploaded performance report) and scores migration difficulty, feature-by-feature, plus a Postgres sizing recommendation.

docker run -p 8090:8090 \ -v polyadvisor-data:/data \ ghcr.io/polygres26/polyadvisor:latest
ghcr.io/polygres26/polywire

PolyWire

Speaks Oracle, MySQL, SQL Server, Postgres, MongoDB, DynamoDB, and Amazon SQS wire protocols, translating and routing every one of them to real Postgres.

docker run -p 19090:19090 -p 15432:15432 \ -e POLYWIRE_PG_HOST=<host> \ ghcr.io/polygres26/polywire:latest
